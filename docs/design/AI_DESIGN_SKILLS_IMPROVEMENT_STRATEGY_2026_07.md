## 0. 북극성 (유지)

> 관공서 미학이 지배하는 카테고리에서 이탈한다. Paradiso는 "비자 조회 도구"가 아니라
> **이주라는 인생 서사를 다루는 에디토리얼** — `Club Paradiso`가 펴내는 도착의 서사다.
> **단, 성공은 "감정"이 아니라 행동 지표로 증명한다**(§9). 감정은 결과이지 지표가 아니다.

이 제품의 1차 과업(JTBD)은 **"내 답을 빠르게·정확하게·믿을 수 있게 찾기"** 다.
세계관은 이 과업을 *돕는 한에서만* 정당하다. 과업과 충돌하면 과업이 이긴다.

## 3. 시그니처 제스처 — 신규 구축·다운스코프 (정정 반영)

막당 하나의 제스처. **전부 CSS/저비용 우선, WebGL은 검증 후 옵션.**

### 🗺️ 1막 Visable — "정리되는 순간 (The Resolve)" *(신규 구축)*
검색 결과가 뜰 때 결과 카드가 **차분한 stagger로 정렬**되어 "복잡함 → 나의 명료함"을 보여준다.
- **구현:** CSS `@keyframes`(opacity/transform만, GPU 합성). View Transitions는 **CSS-only로 가능한 범위만**, 메인 스크립트 수정이 필요하면 착수 전 오너 예외 승인(정정 B).
- **불변:** Emerald ≤3/화면, reduced-motion=즉시 정적 정렬, LCP 비차단, 상태머신 `landing→searching→searched` 로직 불변.

### 🌒 2막 Waymaker — "동행의 순간 (The Companion)"
스텝 전환에 방향(다음=우, 뒤=좌)을 주어 "함께 이동" 감각. 커버리지 배지·`.wm-card-hero`에 조율된 단일 톤 온기.
- **정정:** "조각조각 조립되는 패킷"은 **반복·급한 사용자에게 정보 지연**이 될 수 있음 → 패킷 리빌은 **1회성·빠름(≤380ms 전체)**, 정보 자체를 늦추지 않음. 신뢰·커버리지 카피는 **즉시** 노출(과대주장·지연 금지).
- **불변:** 아이콘+텍스트 커버리지 배지, reduced-motion 전면 중화(L359).

### 🏡 3막 New Home — "도착의 순간 (The Arrival)" *(P2로 강등 + CSS 다운스코프)*
`You Belong Here` 위로 **따뜻한 빛이 서서히 차오르는** 배경.
- **정정(WebGL→CSS):** 기존 `new-home.html:149–153` `radial-gradient` 워시를 계승해 `@keyframes`로 `background-position`/`opacity`만 느린 루프(GPU 합성, 메인스레드 0). 1.35MB 단일파일에 WebGL 런타임+폴백을 얹지 않는다(디자이너 검증: LCP/INP 예산·유지보수 순부담).
- **텍스트 대비(WCAG):** 움직이는 그라데이션 **위에 텍스트 금지**. 카피는 솔리드/반투명 스크림 위에만, `primary-deep`+`neutral` 규칙 적용(REBRAND의 Emerald+흰텍스트 3.21:1 실패 회피).
- **불변:** reduced-motion·저사양=정적 워시 자동 강등, `.nh-caution` 공식 톤 불변.

## 4. 아트 디렉션 정전 (정정 반영)

### 4.1 타이포그래피 — 조판이 주인공, 폰트는 라틴 워드마크만
- **한국어·다국어 = Pretendard 에디토리얼 조판**으로 승부(큰 헤드라인·정교한 자간/행간·`keep-all`). 표현형 폰트를 헤드라인에 쓰지 않는다.
- **표현형 디스플레이 1종 = 라틴 워드마크(Visable/New Home) 한정.** 15로케일(RTL 아랍어·태국어·CJK·키릴)에서 헤드라인 폰트 스와핑 금지 — 라틴 외 로케일은 자동으로 Pretendard 조판으로 강등(규칙 명문화).
- **폰트 정리 과제:** 이미 로드된 Unbounded/Pixelify/Space Mono 3종(archive_diary 전용)을 격리·preload 재검토. 문서의 폰트 예산은 "3종 로드 중"이라는 현실 위에서만 논한다.

### 4.2 색·질감 — 온기는 civic_editorial이 담당
- **civic_editorial(warm paper `#F4EFE4`/ink `#0E1F1A`, Emerald 단일)** 을 아날로그 온기의 정체성으로. **토스 블루·제네릭 테크 그라데이션 금지**(REBRAND §2) 재확인.
- 은은한 그레인/종이 질감은 **정적 텍스처**(성능 무해)로만.
- ⚠️ **archive_diary(블루 `#2F5EFC` 키치)는 "아날로그 온기" 북극성과 충돌.** 승격 보류. 유지/재정렬/축소는 §7 별도 결정.

### 4.3 모션 = 숨, 단 reduced-motion은 정직하게 "끄기"
공유 모션 토큰으로 3막 통일(추가 전 **실제 duration 감사**부터 — 현 코드 `0.18s`·`0.25s`·`0.7s` 산발):
```
--motion-fast:120ms  --motion-base:180ms  --motion-modal:220ms  --motion-reveal:380ms
--ease-out: cubic-bezier(0.22,1,0.36,1)   --ease-arrival: cubic-bezier(0.16,1,0.3,1)
```
- additive만. **reduced-motion = 전면 끄기**(코드 컨벤션 준수). 막당 정적 최종 프레임 1개만 스펙(정정 G — "동등하게 아름다운 정적" 카피 삭제).

### 4.4 이미지 — 스톡 클리셰 거부(유지)
기본은 타이포·질감 중심. 이미지 필요 시 다큐멘터리·존엄·중간 명도·저작권 확인.

### 4.5 보이스 — 하이브리드(유지, 두 검증 모두 승인)
돕는 말 = 해요체 / 보호하는 말 = 공식 톤 불변(REBRAND §5). `Club Paradiso`는 문화 퍼블리셔의 목소리.

## 5. 실행 규율 — 표현 예산(불변, 단 "선언"이 아니라 실측에 묶음)

모든 효과는 세 통화(감정·길찾기·품질)로 값을 치르고, 세 예산 안에 머문다:
- **성능** — LCP 비차단·INP<200ms·폰트 현실(3종 로드) 명시. **저사양 실기기 실측으로 증명**(선언 불가).
- **접근성** — reduced-motion 끄기 + 정적 프레임, WCAG AA(주 CTA AAA), 애니 그라데이션 위 텍스트 금지, 색-only 금지.
- **신뢰** — 면책·공식 톤 불변, 다크패턴 금지, 신뢰 카피 즉시 노출(지연 금지), `CITATION_VERIFICATION_NOT_WIRED` 과대주장 금지.

## 7. 거버넌스 — 자기 가드레일 우회 금지 (PM 반려 반영)

rev.3은 REBRAND §6·UX Lock §2를 **스스로 열어** 파티클·WebGL·표현형 폰트를 정당화했다(스코프 크립). rev.4는 이를 분리한다:

- **가드레일 개정(§6/§2)은 이 전략의 검증 게이트(§8 P0)를 통과한 뒤 별도 오너 승인 건으로.** 전략이 자기 제약을 스스로 풀고 진행하지 않는다.
- **UX Lock §2(9)(10) stale 정정**(삭제된 starCanvas/스포트라이트 보존 조항)은 사실 정정이므로 즉시 가능 — 단 이는 *표현 확장*이 아니라 *현실 반영*.
- **archive_diary 블루 vs Emerald-단일** 충돌은 별도 디자인 결정으로 분리.
- ⚠️ **UX Lock §2 코드 보존 계약(메인 스크립트 바이트·`id`·`data-action`·`data-vcode`·`PARADISO_*`·React/Babel 미도입)은 절대선 불변.**
