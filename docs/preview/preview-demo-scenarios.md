# PreView by Paradiso — 데모 시나리오 3종

> 각 시나리오는 입력 → 생성 결과 → API/폴백 거동 → 출처 패널 → "MVP가 주장하지 않는 것"의 순서로 기술한다.
> 공통 전제: 서비스키가 백엔드에 설정되어 있으면 공관 카드는 "공공데이터 API 기반"으로,
> 없으면 폴백 문구와 함께 "MVP 샘플 데이터"로 렌더링된다.

---

## 시나리오 1 — 베트남 유학 준비생

**입력**
- 현재 체류국: 베트남 · 국적: 베트남 · 목적: 유학·학업 (study) · 희망 언어: 한국어

**생성 결과**
- **공관 카드** — 백엔드 프록시(`/api/preview/mission?country=VN`)가 성공하면 외교부 재외공관 정보 API 응답(공관명·유형·주소·연락처)이 "공공데이터 API 기반" 배지와 함께 표시된다. 실패 시 주베트남 대사관·주호치민 총영사관 샘플 카드(연락처는 미수록, "공식 원문 확인 필요")가 "MVP 샘플 데이터" 배지와 함께 표시되고 상단 상태 표시줄에 폴백 문구가 뜬다.
- **입국 전 확인 카드** — 사증 면제협정 스냅샷 기준 "공식 원문 확인 필요" 상태와 확인 포인트 2개(외교부 원문에서 베트남 항목 확인, 관할 공관 공지 확인)를 보여준다. 무사증 가능 여부를 단정하지 않는다.
- **공관 공개 안내 카드** — 주호치민 총영사관 공지·구비서류 게시판의 공식 경로 참조가 "본문 미수집 · 공식 원문 확인 필요" 라벨과 함께 나온다. 발췌를 완전한 체크리스트로 표시하지 않는다.
- **매뉴얼 기준 참고 카드** — 법무부 매뉴얼 2026.6 판독본에서 추출한 유학(D-2)·일반연수(D-4) 헤딩과 "발급 경로 단서"(사증발급인정서·첨부서류 절 존재)가 페이지 출전과 함께 표시된다. 요구서류 목록은 표시하지 않는다.
- **안전 참고 카드** — "샘플 미수록 · 공식 원문 확인 필요" 안내.
- **체크리스트 카드** — 여권 확인 → 관할 공관 확인 → 사증 필요 여부 확인 → 공관 공식 안내 확인 → 접수 방식 확인 + 유학 목적 항목(교육기관 안내와 공관 안내 교차 확인).
- **문의 문장 카드** — "안녕하세요. 저는 베트남 국적자이며, 유학·학업 목적으로…" 한국어 문의 예시.
- **출처 카드** — 재외공관 정보 API / 사증 면제협정 파일데이터 / 공관 공식 게시판 / 매뉴얼 참고 레이어 / MVP 샘플, 각각 증거 수준 라벨과 함께.

**이 시나리오에서 MVP가 주장하지 않는 것** — D-2 발급 가능성, 필요 서류 목록, 무사증 여부, 접수 예약 방식.

## 시나리오 2 — 몽골 단기 출장 준비 기업인

**입력**
- 현재 체류국: 몽골 · 국적: 몽골 · 목적: 비즈니스·상용 (business) · 희망 언어: English

**생성 결과**
- **공관 카드** — API 성공 시 주몽골 대사관 레코드("공공데이터 API 기반"), 실패 시 샘플 카드 + 폴백 문구.
- **입국 전 확인 카드** — 몽골 항목 "공식 원문 확인 필요" + 확인 포인트.
- **공관 공개 안내 카드** — 주몽골 대사관 대표 페이지 참조(본문 미수집 라벨).
- **매뉴얼 기준 참고 카드** — 단기취업(C-4)·단기방문(C-3) 헤딩 + 발급 경로 단서. C-3 카드에는 전자사증 절 존재 단서가 포함되지만, 적용 대상 판단은 "매뉴얼 원문과 관할 재외공관 공식 안내 확인 필요"로 안내된다.
- **체크리스트 카드** — 공통 5단계 + 비즈니스 항목(초청·일정 관련 공관 공지 확인). 희망 언어가 English이므로 각 항목에 영어 보조 문장이 붙는다.
- **문의 문장 카드** — 한국어 예시와 함께 English 문의 예시가 표시된다.
- **출처 카드** — 시나리오 1과 동일 구조(몽골 소스 세트).

**이 시나리오에서 MVP가 주장하지 않는 것** — C-3/C-4 중 어느 자격이 맞는지의 판정, 초청장 요건, 수수료·처리기간.

## 시나리오 3 — 우즈베키스탄 교환·공공외교 프로그램 참가자

**입력**
- 현재 체류국: 우즈베키스탄 · 국적: 우즈베키스탄 · 목적: 교환·공공외교 프로그램 (exchange) · 희망 언어: 기타(현지어)

**생성 결과**
- **공관 카드** — API 성공 시 주우즈베키스탄 대사관 레코드, 실패 시 샘플 카드 + 폴백 문구.
- **입국 전 확인 카드** — 우즈베키스탄 항목 "공식 원문 확인 필요" + 확인 포인트.
- **공관 공개 안내 카드** — 사증 안내 게시판과 "[주요 안내] 각 비자 신청 종류별 구비서류 안내" 게시글의 공식 경로 참조. 제목은 검색 색인 기준임과 본문 미수집이 명시된다.
- **매뉴얼 기준 참고 카드** — 교환 목적은 유학(D-2) 헤딩을 참고로 보여주되, 프로그램 유형에 따라 세부 절차가 다를 수 있으므로 공식 원문 확인 필요 안내가 붙는다.
- **체크리스트 카드** — 공통 5단계 + 프로그램 주관기관 안내와 공관 안내 교차 확인 항목.
- **문의 문장 카드** — 한국어 예시 + English 예시. 현지어 지원 여부는 "공관 지원 여부 확인 필요"로 안내된다.
- **출처 카드** — 우즈베키스탄 소스 세트.

**이 시나리오에서 MVP가 주장하지 않는 것** — 교환 프로그램의 체류자격 세부약호 판정, 게시글 본문 내용, 서류 목록.

## 공통: 지원 범위 밖 국가 (unsupported fallback)

현재 체류국에서 "기타 국가"를 선택하면:
- 경고 콜아웃: "선택한 국가는 아직 PreView MVP 샘플 범위(베트남·몽골·우즈베키스탄)에 없습니다…"
- 공관 카드는 일반 안내(외교부 재외공관 정보에서 확인)로, 체크리스트·문의 문장은 일반형으로 생성된다.
- 어떤 국가별 사실도 만들어내지 않는다.
