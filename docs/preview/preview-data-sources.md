# PreView by Paradiso — 데이터 소스 문서

> 이 문서는 PreView MVP가 참조하는 모든 소스를 성격별로 구분해 기록한다.
> 기계가 읽는 원본은 `data/preview/preview-source-registry.json`이다.
> 검증 맥락: 이 MVP를 만든 빌드 환경에서는 `*.go.kr` 호스트 접근이 차단되어(프록시 정책 403)
> 어떤 공식 페이지도 직접 열람하지 못했다. 아래 "검증 상태"는 검색 색인·공개 클라이언트 코드
> 교차 확인 수준을 정직하게 표기한 것이며, 실키 호출로 재검증되기 전까지 스키마 세부는 확정으로 간주하지 않는다.

## B. 공공데이터포털 파일데이터

- **외교부_국가별 사증 면제협정 체결현황** — 페이지 `data.go.kr/data/15099235/fileData.do` (관측 파일 버전 접미사 `_20220324`).
  - PreView의 핵심 외교 데이터 소스 중 하나. `data/preview/visa-waiver.snapshot.json`으로 정규화한다.
  - 이번 빌드에서는 파일을 내려받지 못해 스냅샷은 **데이터셋 참조 + 국가별 미확인 상태**만 담는다 (컬럼 스키마·uddi 자동변환 API는 null 유지, 추측 금지).
  - 과대해석 금지: 사증 면제협정 현황은 **입국 전 확인 맥락** 자료이지, 사증 발급 승인 데이터가 아니다. 또한 외교부 체결현황 목록은 한국 국민 출국 방향 서술이 섞여 있어 "한국 입국 무사증"과 동일시하면 안 된다.

## C. 재외공관 공식 공개 웹 자료 (overseas.mofa.go.kr)

- 허용 호스트: `mofa.go.kr`, `www.mofa.go.kr`, `overseas.mofa.go.kr` 만.
- MVP 허용목록: 주베트남 대사관(`/vn-ko/`), 주호치민 총영사관(`/vn-hochiminh-ko/`), 주몽골 대사관(`/mn-ko/`), 주우즈베키스탄 대사관(`/uz-ko/`).
- 수집은 `scripts/preview/collect_mission_notices.mjs` — **수동/오프라인 데이터 준비 스크립트**이며 preview.html 런타임에서 호출되지 않는다. 저요청(요청 상한 8), 타임아웃, 명시 UA, 링크 추적 금지.
- 이번 빌드 환경에서는 접근 차단으로 본문 미수집 → 스냅샷은 검색 색인으로 확인된 공식 경로 참조만 담고 전부 "공식 원문 확인 필요"로 표기.
- **이 갈래는 공공데이터포털 API가 아니다.** 공식 공개 웹 자료로만 분류한다.

## D. 업로드 사증발급 매뉴얼 (HWP) 참고 레이어

- `scripts/preview/import_visa_issuance_manual.py`가 HWP/HWPX/DOCX/TXT를 받아 최소 참고 스냅샷(`data/preview/visa-issuance-manual.snapshot.json`)과 감사 보고서(`audits/preview/visa-issuance-manual-import-report.md`)를 만든다.
- 이번 스냅샷 입력: 리포지토리에 이미 존재하는 법무부 **사증발급 안내매뉴얼 2026.6 판독본**(`backend/data/sources/manuals/260617_visa_manual_readable.txt`). 새 원본 파일을 커밋하지 않았다.
- 추출 원칙: 헤딩·발급 경로 단서(절 존재 여부)만 기록. 요구서류·요건을 요약·생성하지 않는다. 장문 원문 덤프 금지. 모든 레코드는 `evidenceLevel: manual_reference` + `requiresOfficialMissionCheck: true`.
- **이 갈래는 외교부 공공데이터 API가 아니다.** 법무부 매뉴얼 기준 참고 레이어이며, PreView의 주 소스가 아니다.

## E. 로컬 MVP 샘플 데이터

- `assets/js/preview/preview-data.js`. API 실패·키 미설정 시 폴백 렌더링 전용.
- 항상 "MVP 샘플 데이터" 배지·문구와 함께 표시된다.
- 전화번호·수수료·처리기간·서류목록 등 세부 사실을 만들어 넣지 않는다. 미확인 항목은 "공식 원문 확인 필요".

## 과대주장 금지 (Do not overclaim)

- 사증 발급 여부·심사 결과 **예측 없음**.
- 공관 내부 심사 절차·기준에 대한 접근이나 재현 **없음** (그런 데이터는 이 서비스에 존재하지 않는다).
- **보장된 체크리스트 없음** — 체크리스트 카드는 확인 절차 안내다.
- MVP에 **전 세계 공관 실시간 수집 없음** — 범위는 3개국 허용목록.
- 공관 홈페이지 게시글 파싱을 **공공데이터포털 API라고 표기하지 않는다**.
- 업로드/로컬 HWP 매뉴얼을 **외교부 공공데이터 API라고 표기하지 않는다**.
