# 2026-11-02 법무부 공지 반영: E-2 마약검사 및 지정 의료기관 명부

## 출처
- 사용자 제공 법무부 공지: `회화지도 강사(E-2) 마약검사 항목 등 변경 안내문(국문).pdf` (1쪽)
- English notice: `회화지도 강사(E-2) 마약검사 항목 등 변경 안내문(영문).pdf` (2쪽)
- 의료기관 명부: `법무부지정_건강검진가능_의료기관현황(2026.11.2.).pdf` (36쪽, 최종 연번 1130)
- 이 문서는 별도 제공된 공식 PDF 자료에서 전사한 변경사항을 기록한다. 원문 PDF 파일은 리포지터리에 포함하지 않았다.

## E-2 마약검사 신규 기준

| 분류 | 내용 |
| --- | --- |
| 적용 기준일 | **2026년 11월 2일** |
| 적용되는 접수 | 해당 날짜 **이후 접수된 사증발급인정서 또는 비자 신청** |
| 제출 시점 | 위 접수 대상자의 **외국인등록 시** |
| 변경 항목 | MA(필로폰), THC(대마), COC(코카인), OPI(아편) + MDMA(엑스터시), KET(케타민) |
| 총 항목 수 | 기존 4종 → **6종** |
| 검사 유효기간 | **결과 판정일로부터 4개월** |
| 의료기관 | 기존 법무부 지정기관의 **재지정 신청 불필요** |

**주의:** 외국인등록일이 11월 2일 이후라는 이유만으로 모든 기존 E-2 접수자를 신규 6종 검사 대상으로 표시하지 않는다. 또한 구 체류 매뉴얼의 E-2 학교 보조교사 등 검사서 제출 면제 가능성과 본 공지의 관계는 단정하지 않고 별도 확인 대상으로 남긴다. 국내 체류자격 변경허가 신청에 6종 검사 기준이 자동 적용된다고 확대 해석하지 않는다.

## 의료기관 최신 명부

- 원본 명부의 연번 1~1130, 17개 광역권 데이터를 `data/designated_medical_institutions_2026_11_02.json`에 등록.
- 기존 2026-04-30 명부는 추적용으로 보존.
- 진료 가능 검사 종류, 예약 여부, 비용 및 준비물은 병원별 확인이 필요하다. **지정 의료기관 = 해당 6종 검사를 항상 수행한다**는 뜻이 아니다.
- 추출 처리 중 연번 231의 빈 지역 칸은 주소 및 인접 행을 근거로 경기로 정규화했고, 이웃 행으로 넘친 주소 파편 10건은 PDF 레이아웃 검토로 정정했다.

## 제품 적용 지점
- `src/features/finders.js` 및 `src/data/paths.js`: 새 명부 경로 및 지역 인덱스 설정.
- `index.html`: 의료기관 찾기 모달에서 날짜 조건과 6종 검사 안내.
- `src/i18n/runtime.js` 및 `data/i18n/*.json`: 지원 언어별 공지, 최신 명부 출처.
- `data/policies/e2_drug_screening_2026_11_02.json`: E-2 외국인등록 적용 요건 및 원문 근거를 버전 관리(생성형 비자 데이터와 분리).
- `scripts/validate_designated_medical_institutions.py`: 신규 1,130건 데이터 유효성 검사.

## 회귀 확인
- `python3 scripts/validate_designated_medical_institutions.py`

- `npm run build`
