# HWP 대조 검증 보고서 (PDF ↔ HWP)

## 검증 대상
- `visa_manual_2026_05_21.hwp` (HWP 5.1.0.1, 배포용/distribution, 압축)
- `stay_manual_2026_05_21.hwp` (HWP 5.1.0.1, 배포용/distribution, 압축)
- 비교 기준: 기존 PDF 추출 결과(`visa.txt`, `stay.txt`)

## 추출 방법 (정직한 기록)
- HWP는 **배포용 문서**라 본문이 `BodyText`가 아닌 **암호화된 `ViewText`** 스트림에 있음. 일반 텍스트 변환(hwp5txt)은 visa 파일에서 치명적 파싱오류(`undefined Kind value: 2`), 표를 `<표>`로 비워버림.
- 해결: stay = `hwp5proc xml` → lxml로 표 셀(‖ 구분) 포함 재구성(754KB). visa = pyhwp 저수준 `viewtext` 접근자로 13개 ViewText 섹션 직접 디코드(458KB), 크래시 우회.
- **HWP에는 페이지 번호가 없음**(리플로우 포맷). 따라서 페이지 인용은 PDF가 유일 근거로 유지.

- **sub-code 교차검증: 275개 중 274개 양쪽 완전일치(99.6%).**
- 유일한 불일치 `F-5-27`(stay)은 **허위경보** — PDF에도 존재(라인 18664, "※ F-5-2/3, F-5-6, F-5-7, F-5-14, F-5-27은 별도 지침" 주석). 전체파일 정규식 집합 비교 방식의 차이일 뿐, 실제 내용 누락 아님.
- 서류 항목 본문(예: F-6/A-3 별지 제34호 영역) 표본 대조 시 항목 텍스트 일치(출생증명서 사본, 대사관 협조공한 등). 다단 레이아웃에 따른 항목 인접순서 차이만 존재.

## 결론
1. 기존 PDF 기반 추출물(Part 1~8)은 HWP 원본과 **내용상 동등**. sub-code 인벤토리·서류 마커 수가 1~2건 오차(헤더/목차 언급) 내 일치.
2. HWP는 표 셀 경계가 명시(‖)되어 **서류 리스트 검증·세분화에 더 깨끗한 보조 소스**. 단, 페이지번호 없음.
3. 권장: 페이지 인용은 PDF, 표/서류 셀 구조 정밀 분리는 HWP를 병용. E-7 등 대형 섹션 수동 세분화 시 HWP 셀 텍스트가 유리.
