**주요 추출 한계 (정직한 고지)**
1. 서류 블록은 페이지 단위로 정확히 위치하지만, **어떤 sub-code에 귀속되는지는 기계적으로 확정 불가**. 본문이 좌측 라벨/번호 시나리오로 분기하여 OCR-텍스트만으로 행 귀속이 모호함.
2. 원→번호(①②③) 항목은 정상 추출되나, 다단 레이아웃에서 조건 라벨(좌측열)이 항목 텍스트와 분리·혼입될 수 있음.
3. E-7(특정활동)은 visa pg168-277 / stay pg212-323으로 100쪽 이상이며 직종코드(E-7-1~4 및 수십 개 세부직종)를 포함 — 단일 패스 자동분리는 부분적. 수동 세분화 권장.
4. E-2(체류, pg176~) 등 일부 섹션은 본문에 독립 중앙정렬 헤더가 없어 시작 페이지가 근사치. 해당 행은 NEEDS_PAGE_CITATION.
5. 외부지식·웹검색 미사용. 근거 없는 필드는 추정하지 않고 빈칸/검토표시.

## Part 8. 개발자용 최종 노트

**나중에 데이터 패치 후보로 비교적 안전한 행**
- `document_boundary=universal` 이며 항목 2개 이상인 서류 블록(예: A-1, A-2 공통 첨부서류). 그래도 패치 전 해당 PDF 페이지 1회 육안 확인 권장.

**사람 검토 없이는 패치 금지**
- `patch_readiness=SUBCODE_AMBIGUITY_REVIEW` 전체(110건). sub-code 귀속 미확정.
- sub-code ≥ 8개인 모든 parent(C-3, D-2, D-4, D-8, D-10, E-7, E-8, F-1, F-2, F-3, F-5, G-1 등) — Part 6 참조.
