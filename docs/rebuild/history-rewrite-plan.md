## What a rewrite would do
Remove from **history** (not from the working tree) the generated SQLite index versions and
the superseded manual PDFs/HWPs that are kept as files in `docs/archive` or regenerable by
scripts. The current PDFs (`docs/source-manuals/2026-10-19`, `2026-11-02`) stay in both
history and tree because the site links to them.

Expected reduction (lower bound from the shallow clone): ~95 MB from the SQLite index
versions alone; ~150–200 MB more if superseded PDFs/HWPs are dropped from history. The real
figure needs the full clone.

## Exact commands (for the owner, on a fresh full clone; never on a working checkout)
```bash
git clone --mirror https://github.com/club-paradiso/Visable.git visable-mirror.git
cd visable-mirror.git
pip install git-filter-repo
# 1) measure first
git filter-repo --analyze
less filter-repo/analysis/blob-shas-and-paths.txt
# 2) drop the generated index from history (it is rebuilt by npm run build:manual-index)
git filter-repo --path backend/data/manual_search_index.sqlite3 --invert-paths --force
# 3) optional: drop superseded source PDFs/HWPs from history, keeping the two current editions
git filter-repo --invert-paths --force \
  --path docs/source-manuals/2026-05 --path docs/source-manuals/2026-06 \
  --path docs/source-manuals/2026-06-17 --path docs/source-manuals/2026-07-31 \
  --path docs/source-manuals/2026-09 --path docs/source-manuals/2026-09-01 \
  --path backend/data/sources/manuals
# 4) verify size, then push (THIS IS THE FORCE-PUSH — owner only)
git count-objects -vH
git push --force --mirror https://github.com/club-paradiso/Visable.git
```
After the push every collaborator re-clones; open PRs based on the old history must be
rebased. Vercel and Railway keep working (they deploy the tip, not the history).

## Preconditions the owner should check
- Step 3 removes superseded official manuals from history. If any audit or legal record
  relies on `git log`-level provenance of those files, keep them (skip step 3) or move them
  to a separate archive repository first.
- Protected data files (`visa_data.json`, `doc_master.json`, `backend/data/*.json`) are not
  touched by any of the commands above.
