# 시행규칙 출처 교차검증 리포트 (2026-06-12)

## 목적
사용자 제공 패키지의 `docs/source-manuals/law/rule_1106_full.txt`(별표·별지서식 인쇄본)를
law.go.kr 원본과 교차검증하여 PHASE A 감사의 1차 출처로 사용 가능한지 판정.

## 수집 경로
- law.go.kr 직접 접근(`www.law.go.kr`)은 세션 네트워크 egress 허용목록 밖 → 403 차단.
- 대체 경로: **Legal Data Hunter MCP — `KR/LawGoKr`(국가법령정보센터 미러)** 로 전문 수집 성공.
  - 출입국관리법 시행규칙: `KR-LAW-008494`, https://law.go.kr/LSW/lsInfoP.do?lsiSeq=283059 (시행 2026-01-23)
  - 출입국관리법(본법): `KR-LAW-001707`, https://law.go.kr/LSW/lsInfoP.do?lsiSeq=272921 (시행 2025-07-22)
- 수집 사본: `docs/source-manuals/law/crosscheck/lawgokr_rule_283059_articles.txt`, `lawgokr_act_272921_articles.txt`

### 보완 관계
- law.go.kr API 텍스트는 **조문 본문만** 포함하고 별표 표·별지서식은 미포함.
- 로컬 `rule_1106_full.txt`는 **부칙·별표·별지서식** 인쇄본.
- → 두 파일을 합쳐 시행규칙 전체를 커버. 조문 인용은 crosscheck 사본, 별표 값 인용은 rule_1106_full.txt 기준.

### 한계 (정직성 고지)
- [별표 1] 표의 개별 수치(예: D-10 1년)는 API/외부 미러(ulex, lbox 등 — 모두 egress 차단)로
  **외부 재검증 불가**. 다만 로컬 파일이 공식 인쇄본 포맷 + 버전 일치 + 근거조문 일치이므로
  표 값 신뢰도 **HIGH**로 채택. 표 유래 수치의 감사 confidence 상한 규칙(medium 캡)은
  매뉴얼 다단표에만 적용하고, 시행규칙 별표는 법령 원문으로 취급.

## 감사에 사용할 핵심 법정값 (조문 직접 인용 — HIGH)

### 수수료 (시행규칙 제72조, lsiSeq 283059)
- 체류기간 연장허가: **6만원** (F-6 소지자: 3만원)
- 체류자격 변경허가: **10만원** (영주 F-5로 변경: 20만원)
- 체류자격 외 활동허가: **12만원** (D-2/D-4 시간제취업 등 법무부장관 인정: 2만원)
- 근무처 변경·추가 허가: **12만원**
- 체류자격부여: 8만원 (F-6: 4만원)
- 외국인등록증 발급·재발급: **3만 5천원**
- 단수재입국 3만원 / 복수재입국 5만원
- 수수료 면제(제74조): A-1~A-3, D-8 해당자, 정부·정부출연연구기관 초청 D-1/D-2/D-4의 변경·연장·재입국 등

### 외국인등록 (출입국관리법 제31조, lsiSeq 272921)
- 입국일부터 **90일 초과 체류 시, 90일 이내** 체류지 관할 관서에 등록.
- 면제: ①주한외국공관·국제기구 직원과 가족 ②협정상 특권·면제자와 가족 ③정부초청자 등 법무부령으로 정하는 사람. (면제자도 본인 희망 시 등록 가능 — 제31조제2항)
- 체류자격부여(제23조)·변경허가(제24조)로 90일 초과 체류하게 되는 경우: **그 허가를 받는 때에 등록** (제31조제3·4항).
- 17세 미만 등록증 미발급 가능, 17세 도래 시 90일 내 발급신청 (제33조).

### 체류기간 연장 (출입국관리법 제25조)
- 체류기간이 **끝나기 전에** 연장허가를 받아야 함. 심사기준은 법무부령으로 정함.
