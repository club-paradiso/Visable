# 260731 사증·체류 안내매뉴얼 대상 변경 감사

## 결론

하이코리아의 `체류자격별 통합 안내 매뉴얼(최신)` 공지에 첨부된 260731 HWP 3종과 사용자 제공 파일명이 일치함을 확인했다. 260709 추출본과 260731 본문을 정규화 비교하고, 변경이력이 지정한 E-6·F-1-51·지역특화형 비자 범위를 원문 대조했다.

공식 공지: https://www.hikorea.go.kr/board/BoardNtcDetailR.pt?BBS_SEQ=1&BBS_GB_CD=BS10&NTCCTT_SEQ=1062&page=1

## 반영한 변경

### 예술흥행(E-6-2)

- 기존 데이터의 근거 없는 일반요건인 `지자체장 추천서, 숙소 확인서`를 제거했다.
- 사증발급인정서 경력증명은 원칙 3년 이상이며, 신청일 기준 과거 10년 이내 국내 E-6-2 경력을 인정하도록 보강했다.
- 국내 정상근무 2년 후 출국자는 경력요건을 3년에서 2년으로 완화했다.
- 형사범죄, 100만원 이상 범칙금 통고처분, 출국명령·강제퇴거가 있으면 해당 외국인등록기간의 경력을 인정하지 않는 예외를 추가했다.
- 국내 E-6-2 체류사실이 확인되면 경력증명서 등을 면제하고 체류기간을 합산할 수 있음을 추가했다.

### 국제 입양 외국인(F-1-51)

- 사증발급·체류자격변경: 협약준수입양증명서의 발급 주체를 `체약국의 출신국 또는 보건복지부`로 정정했다.
- 체류기간연장: 협약준수입양증명서도 `체약국의 출신국 또는 보건복지부 발급`으로 정정했다.
- 사증발급, 체류자격 변경, 체류기간 연장 시나리오를 분리하고 각 제출서류·면제조건을 구조화했다.

### 지역특화형 비자

- F-2-R 기본소양을 사회통합프로그램 3단계(사전평가 4단계) 또는 TOPIK 3급으로 완화했다.
- E-7-4R의 고용기업 추천은 현재 1년 이상 근무를 원칙으로 하고, 근로자 귀책 없는 이직은 직전·현재 근무기간을 합산해 1년 이상이면 추천할 수 있도록 반영했다.
- 현 근무처 3년 이상 계속 근무는 별도의 가점 항목으로 구분했다.
- 출입국관리법 위반 행정처분 감점에서 과태료 처분을 제외하도록 문구를 정정했다.
- E-7-4·E-7-4R 동시고용 사업장의 E-7-4 허용인원 기준(내국인 고용인원의 50% 이내) 적용 조건을 71명 초과·135명 이상 분기까지 반영했다.

## 교차검증과 보류

- 2026-08-03 확인 시 국가법령정보센터의 해당 F-2 파목 고시는 여전히 `[시행 2025. 12. 5.] [법무부고시 제2025-495호]`와 종전 4단계·5단계·TOPIK 4급을 표시했다.
- 260731 체류매뉴얼은 새 기준과 `[시행 2026. 8. 3.] [법무부고시 제2026-248호]`를 싣지만, 고시 머리말의 제정일을 `2025. 12. 5.`로 남겼고 같은 장의 한 문단에도 종전 한국어 기준이 남아 있다.
- 따라서 데이터는 변경이력, 기본요건 표, 제출서류, 매뉴얼 내 새 고시 조문이 일치하는 3단계·4단계·3급을 운영 기준으로 반영하되, 문서 내부 불일치는 `manualReviewReason`에 보존했다. 제2026-248호의 국가법령정보센터 등재 전에는 고시 번호·제정일을 검증 완료 법령 메타데이터로 승격하지 않는다.

## 변경하지 않은 보호 파일

`visa_data.json`, `backend/data/visas.json`, `doc_master.json`은 직접 편집하지 않는다. `visa_data.json`은 authoring 빌드 결과로만 갱신한다.
