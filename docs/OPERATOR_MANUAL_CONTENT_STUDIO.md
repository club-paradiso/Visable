# VISABLE 콘텐츠 운영 스튜디오 (Content Operations Studio) 운영자 매뉴얼

- **버전**: v1.0 (Milestone R3)
- **대상**: VISABLE 출입국 서류 정보 운영자, 법률 검토자, 게시 관리자
- **접속 주소**: `https://visable.vercel.app/content-studio.html` (로컬: `http://localhost:8000/content-studio.html`)

---

## 1. 개요 및 운영 철학

VISABLE 콘텐츠 운영 스튜디오는 비개발자 운영자가 GitHub 코드를 직접 건드리지 않고도 **647개 대한민국 출입국 상황별 서류 안내**를 안전하게 수정, 검증, 심사 및 게시할 수 있도록 설계된 전문 관리 시스템입니다.

### 핵심 3대 운영 원칙
1. **647개 전수 보존 원칙 (Zero Data Loss)**:
   체류기간 연장(224), 체류자격 변경(251), 외국인등록·거소신고(172) 총 647개 항목은 임의로 삭제되거나 누락될 수 없습니다.
2. **공식 HTTPS 근거 강제 (Evidence Gate)**:
   법무부 공식 고시, 출입국 외국인정책본부 지침, 하이코리아 공문 등 공식 HTTPS 웹 링크가 등록되지 않은 개정안은 승인할 수 없습니다.
3. **전국 표준과 관서별 차이 분리**:
   26개 출입국·외국인관서의 자체 실무(예: 제주청 유학생 재정입증 특례 등)는 전국 공통 기준을 왜곡하지 않고 별도 오버라이드로 독립 관리합니다.

---

## 2. 권한 체계 (Role-Based Access Control)

스튜디오는 4단계 권한 분리를 엄격하게 적용합니다.

| 역할 (Role) | 주요 권한 | 불허 작업 |
|---|---|---|
| **조회자 (Viewer)** | 647개 서류 항목, 변경 이력, 관서별 차이 열람 | 초안 작성, 승인, 배포 |
| **편집자 (Editor)** | 서류 항목 수정, 신규 개정 초안(Draft) 작성 및 제출 | 초안 승인, 배포 실행 |
| **검토자 (Reviewer)** | 초안 심사, HTTPS 근거 검증, 승인(Approve) / 반려(Reject) | 배포 실행 (Publisher 전용) |
| **게시자 (Publisher)** | 무결성 사전 검증(Pre-publish Validation) 실행 및 운영 배포 | — |

## 3. 화면별 상세 운영 가이드

### A. 로그인 및 세션 관리
1. 상단 로그인 폼에 본인에게 발급된 **운영자 보안 토큰(Operator Token)**을 입력합니다.
2. 토큰은 브라우저 탭 세션(`sessionStorage`)에만 안전하게 보관되며, 탭을 닫으면 자동 폐기됩니다.
3. 인증이 완료되면 우측 상단에 운영자 성명과 역할 뱃지(`EDITOR`, `REVIEWER`, `PUBLISHER`)가 표시됩니다.

### B. 대시보드 (Dashboard)
- **실시간 지표 카드**: 전체 647개 항목, 검증 완료 항목, 검토 대기 항목, 근거 부족 항목, 법령 충돌 의심 항목을 즉시 확인합니다.
- **업무별 분포**: 체류기간 연장(224), 체류자격 변경(251), 등록·거소신고(172)의 현재 진행 상태를 점검합니다.
- **빠른 진입 (Pilot Targets)**: D-2(유학), E-7-1(전문인력), F-4(재외동포), 제주출입국청 요건 등 핵심 민원 자격으로 1클릭 이동합니다.

### C. 자격·서류 편집기 (Visa & Procedure Editor)
1. **검색 및 필터링**:
   - 좌측 검색창에 "D-2", "E-7", "유학", "체류기간 연장" 등을 입력하거나 업무 필터 탭을 누릅니다.
2. **항목 선택 및 상세 열람**:
   - 목록에서 항목을 클릭하면 우측에 구조화된 편집 양식이 나타납니다.
3. **서류 항목 수정**:
   - **일반인용 쉬운 명칭**: 행정 용어를 탈피하여 외국인이 직관적으로 이해할 수 있는 명칭 입력.
   - **필수 제출 서류**: 모든 신청인이 제출해야 하는 공통 서류 (줄바꿈으로 구분).
   - **조건부 제출 서류**: 특정 요건(예: 학사경고, 실태조사 대상 등)에만 해당하는 서류.
   - **예외 및 대체 조건**: 특정 조건 충족 시 서류 면제 규정.
   - **대리 신청 여부**: 본인 직접 접수 필수인지, 행정사·기업 담당자 위임 접수 가능한지 설정.
4. **공식 근거 등록 (Evidence Gate - 필수)**:
   - **공식 근거 URL**: 반드시 `https://`로 시작하는 법무부/하이코리아 공식 링크 입력.
   - **근거 문서명 및 시행일**: 예: `2026.09 외국인체류 안내매뉴얼`, `2026-09-01`.
   - **개정 사유**: 개정 배경과 변경 취지를 기록 (초안 이력에 영구 보존).
5. **초안 저장 및 검토 요청**:
   - `임시 저장 (Save Draft)`: 작업 중인 내용을 보관합니다.
   - `검토 요청 (Submit for Review)`: 검토자 대기열로 초안을 인계합니다.

### D. 관서별 차이 관리 (Office Overrides)
1. 26개 출입국·외국인관서 목록에서 특정 관서(예: 제주출입국·외국인청)를 선택합니다.
2. `신규 관서 요건 등록` 버튼을 클릭합니다.
3. 대상 체류자격, 신청 업무, 요건 유형(`추가 서류`, `조건부 면제`, `접수 제한`, `관할구역 특례`)을 지정합니다.
4. 해당 관서의 공식 공지 URL(HTTPS)을 첨부하여 등록합니다.
5. 등록된 요건은 대국민 화면의 전국 공통 안내를 변형하지 않고, 관서 선택 시 별도 유의사항으로 안내됩니다.

### E. 검토 및 승인 대기열 (Review & Approval Queue)
1. **심사 대상 확인**:
   - `검토·승인 대기열` 탭에서 `SUBMITTED` 상태의 초안을 확인합니다.
2. **시각적 비교 (Visual Diff)**:
   - `비교 (Diff)` 버튼을 눌러 기존 게시본 대비 추가(녹색), 삭제(적색), 변경(노란색)된 내용을 한눈에 검토합니다.
   - "법적 및 행정적 영향도 분석" 배너를 확인하여 신청인에게 부당한 입증 책임이 전가되지 않는지 점검합니다.
3. **승인 (Approve)**:
   - 공식 HTTPS 근거가 검증된 경우 승인을 진행합니다.
   - 공식 HTTPS 링크가 누락된 초안은 시스템이 승인을 원천 차단합니다.
4. **반려 (Reject) / 보완 요청 (Request Changes)**:
   - 명확한 사유를 기재하여 작성자에게 보완을 요구하거나 반려합니다.

### F. 게시 파이프라인 (Publish Release Pipeline)
1. **1단계: 무결성 사전 검증 (Pre-publish Validation Gate)**:
   - `검증 실행` 버튼을 클릭합니다.
   - 시스템이 647개 항목 전수 보존, 3개 업무별 건수 일치, ID 무결성을 100% 자동 검증합니다.
   - 검증 실패 시 배포가 시스템적으로 차단됩니다.
2. **2단계: 배포 실행 (Publisher 권한 필수)**:
   - 릴리스 버전 태그(예: `rel-20261019-1`) 및 개정 요약 노트를 작성합니다.
   - `운영 게시 배포 확정`을 클릭하면 승인된 초안들이 기준 데이터로 즉시 게시됩니다.
   - 모든 배포 이력은 `checklist_releases` 테이블에 영구 보존됩니다.

## 4. 장애 및 비상 복구 절차

1. **승인 취소 및 긴급 롤백**:
   - 오배포가 발생한 경우, 직전 정상 릴리스 스냅샷 또는 이전 판본의 초안을 재승인하여 즉시 릴리스를 재실행합니다.
2. **시스템 지원 문의**:
   - 데이터 무결성 오류 또는 보안 토큰 관련 문의는 VISABLE 엔지니어링 팀(`support@visable.kr`)으로 접수하십시오.
