절차 세분류는 B2가 우세하다. B-fixed의 세부 코드 보존과 상태 방향 개선이 전체의 출시 적합성을 뜻하지 않는다. B1의 세분류는 원래 출력하지 않으므로 0점으로 취급하지 않았다. 중요 오류 수는 출력 범위가 다른 기준 간에 직접 비교할 수 없다.

## 구현과 방어 범위

- 명시적 코드의 부모·세부 부분과 접미 문자(예: `E-7-4R`, `F-2-R`, `D-10-T`)를 보존한다. 토큰 경계에서 더 긴 잘못된 문자열의 일부만 취하지 않는다. 구문 인식은 해당 자격의 법적 실재나 서류 요건을 확인하지 않는다.
- 방향 표지가 있는 전환 질의에서는 목표 자격을 질의의 자격으로, 현재와 목표는 각각 별도 필드로 기록한다. 방향 없는 다중 코드는 확인을 요구한다. 한국어·영어·중국어·일본어·베트남어·러시아어 예제를 회귀 검사했다.
- 재입국은 체류 절차, 사증발급·사증발급인정서는 사증 절차로 분리한다. 전자사증은 현재 사증발급 대분류 수준이다. 별도 법률·원본 매뉴얼·제출서류의 내용은 고치지 않았다.
- 배포 문맥 테스트의 외부 공급자 호출을 503 모의 응답으로 격리하고 소켓을 막았다. 실제 외부 모델 질의를 실행하지 않았다.

## 평가 한계와 후속 작업

v0 분류 라벨에 인적 검증이 없고, 데이터 검증에 템플릿 공유 경고 16건이 남아 있다. adversarial_holdout에는 이 분류 작업 항목이 없어 독립 일반화 수치를 주장할 수 없다. 중단으로 복구된 구현에 대해 dev/test를 재평가했으므로 이 수치는 사후 관찰이다. 향후 절차 세분류(전자사증, 카드 재발급, 등록 정보 신고, 근무처 신고, 시간제 취업, 조건 변경)를 독립 설계하고, 공식 근거로 인적 검수한 새 v1 평가셋과 처음 보는 템플릿·언어로 재측정할 것. 현재 PR은 초안이며 출시 게이트를 통과하지 않았다.
