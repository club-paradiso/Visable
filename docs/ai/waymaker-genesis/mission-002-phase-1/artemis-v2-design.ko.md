# Artemis v2: 기초 질의응답 요구사항과 평가 계획

구체적인 로컬 프로토타입 계약·구현 순서는
[Phase 1.1 구현 계획](artemis-v2-prototype-plan.ko.md)을 참조한다.

상태: 설계안. Mission 002 Phase 1에서 모델 학습, 증류, 추론 모델 배포 또는 운영 연동을 실행하지 않는다.

## 범위

공개되고 사용 승인을 받은 법령·매뉴얼 근거에서 단일 질문의 절차, 서류, 기한, 비용, 신청 경로를 찾아 짧게 설명한다. 한 답변의 각 법적 주장에는 자료 식별자, 시행일·기준일, 조문 또는 매뉴얼 위치를 연결한다. 자료가 누락되거나 충돌하면 답을 보류하고 필요한 사실을 묻는다. 자격의 허가 가능성이나 개별 사건 결론을 예측하지 않는다.

| 단계 | 요구사항 |
|---|---|
| 입력 이해 | 질문 언어, 명시적 부모/세부 자격, 현재/목표 방향, 절차 종류, 사건 기준일을 별도 필드로 기록. 불명확한 다중 코드는 확인 요청. |
| 근거 검색 | 승인된 공개 출처와 해당 기준일에 효력 있는 판본만 사용. 법령 신원과 본문·원본 매뉴얼 승인을 구분. 출처 충돌이나 폐지·장래 시행을 표시. |
| 답변 생성 | 확인된 범위의 사실만 주장하고 서류 목록을 부모 코드에서 자동 상속하지 않음. 재입국, 체류 연장, 사증 발급 절차를 분리. |
| 검증 | 인용 위치와 내용 일치, 시행일 적합성, 세부 코드·절차 보존, 개인정보 미노출, 근거 부재시 보류. 실패 시 확인 질문 또는 담당 기관 안내. |
| 운영 전제 | 사람의 법률·매뉴얼 검토, 감사 가능한 출처 버전, 평가 게이트와 롤백 기준이 선행되어야 함. |

## 평가 설계

1. v0는 B1/B2/B-fixed의 탐색 비교에만 사용한다. 분류 라벨의 인적 확인이 없고 템플릿 겹침이 16건이므로 모델 훈련·출시 근거로 사용하지 않는다.
2. 새 v1의 기초 QA 300건을 계획한다: 체류·사증·국적과 서류/기한/비용/경로 질문을 언어·절차·세부 코드별로 층화한다. 공개 가상 사례만 작성하고 실제 민원인 정보는 제외한다.
3. 법무·도메인 검수자가 법령·고시 식별자, 시행일, 원문 위치, 기대 답변/보류 사유를 승인한다. 같은 사건 틀, 출처 문단, 번역 변형을 훈련과 평가 사이에 공유하지 않는다.
4. 독립 test와 최초 1회 holdout에서 답변의 주장별 출처 충실도, 시간적 정확성, 세부 코드·절차 구분, 정확한 보류율과 위험 오류 건수를 집계한다. 오류별 사례·분모·미평가 항목을 함께 공개한다. 위험 오류 0건, 출처 일치와 시간 적합성 인적 검수 완료를 출시 전 필수 게이트로 제안한다. 통계 신뢰구간과 언어별 분모도 제시한다.
5. B2와 변경 없는 B1, B-fixed 및 근거 검색 전용 방식에 동일 입력/동일 출처 스냅샷을 적용한다. 모델 선택·학습은 별도 승인된 후속 단계에서 결정한다.

## 남은 위험

법령 신원 검증이 본문 및 제출서류의 정확성을 보증하지 않는다. 새 고시의 원문과 추출 표제가 불일치할 수 있다. 수동 승인되지 않은 자료가 섞이면 잘못된 서류를 제시할 수 있다. 다국어 의역과 복합 전환 질의는 판단 근거를 흐린다. 자료 갱신 시 효력일 및 QA 회귀 평가가 다시 필요하다.
