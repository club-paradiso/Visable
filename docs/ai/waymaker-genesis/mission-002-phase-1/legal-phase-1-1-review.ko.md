# PR #706 Phase 1.1 법령 검증 범위 재점검

2026-10-26. 기준 main 0d6171a0df1c3f4f48d3c4dffc8f13b9ab7e0752.
법령 신원은 공식 국가법령정보센터 표제와 연결된 공개 법령 조회로 재대조했다.
출입국관리법 290729/2026-10-02, 시행령 290501/2026-10-02,
국적법 시행령 246165/2022-12-20, 국적법 시행규칙 291055/2026-10-02는 일치했다.
D-3 훈령 제목은 법무부의 훈령 제1414호 공표와 일치했다.

## 발견한 결함과 수리

새 MST에 과거 검토일과 CURRENT_TEXT_READ를 그대로 붙인 것은 현행 조문 재검증으로 오해할 수 있었다.
법·시행령과 시행규칙의 일반 요약은 BODY_REVALIDATION_PENDING으로 명시하고,
identity_checked_on, body_checked_on, body_review_mst, verification_scope를 구분했다.
checked_on은 과거 특정 요약 검토일로 남고 최신 전체 조문의 승인일로 쓰지 않는다.
검색 근거 패널과 빠른 답변에도 현행 조문 재검토 필요 문구를 KO/EN으로 표시한다.
원래 조문 요약·서류·원본 매뉴얼은 재작성하지 않았다.

추가로 **출입국관리법 시행규칙은 이미 2026-10-23 판으로 바뀌어 있었다**.
PR 최초의 289833(2026-09-15)을 현행으로 유지하면 안 된다.
공식 MST 291289, 법무부령 1172호, 공포·시행 2026-10-23으로 신원을 수선하고 document_help 링크를 맞췄다.
다른 조문·서식 전체의 변경 영향을 확인한 것은 아니므로 일반 요약은 검토 대기로 남긴다.

제73조는 예외적으로 기준일 2026-10-26을 지정해 현재 본문을 재조회하고 제1125호 부칙과 함께 대조했다.
시행일 없는 get_law_text(mst=291289)는 장래 개정의 카드 결제 문구를 반환했지만,
efYd=20261026 조회는 현행 문구(등록증 현금 또는 현금 납입 증표)를 반환했다.
따라서 현재 본문과 2027-09-16 전환을 유지하고 이 조문만 ARTICLE_TEXT_AT_REFERENCE_DATE_READ로 기록한다.
이 상태도 법령 전체·서식 전체·개별 자격의 적법성을 보증하지 않는다.
별지 제34호 링크는 과거 대조 판본임을 body_review_mst와 검토 대기 상태로 명시한다.

## 국적법 시행규칙 2026-10-02 서식 영향

[공식 제개정문](https://www.law.go.kr/LSW/lsRvsDocListP.do?chrClsCd=010202&lsId=006766&lsRvsGubun=all)의 해당 개정령은
**별지 제2호서식 귀화허가 신청서 제8쪽 중 기관명 검찰청을 공소청으로 바꾸는 내용**이다.
법령mcp의 공식 별지 제2호 원문 제8쪽도 이 기관명과 일치했다.
부칙의 시행일은 2026-10-02다.
이 개정문에서 다른 서식이나 첨부서류 목록을 일괄 변경한 것으로 해석하지 않는다.
contentVerified=false는 유지한다. 저장소의 서식 원본·국적 제출서류 목록을 추측으로 고치지 않는다.
개정문, 서식의 지정 위치, 조회 방법은 legal-evidence.json의 phase_1_1에 기록했다.

## F-4 고시 충돌 후속 조치 및 통과 조건

공식 공개 고시는 제2026-65호(2026-02-12), 매뉴얼 일부는 제2026-35호로 표기한다.
원문 PDF/HWP·전사·코퍼스를 바꾸지 않고 충돌 레이어를 따로 두어야 한다.
이번 PR의 추출기 주석만으로 검색과 답변에서 충돌이 해결됐다고 주장하지 않는다.

1. **구간 등록**: source_id·원본 해시·쪽·정확한 앵커를 기준으로 충돌을 등록한다.
   한국어·영어·중국어 서약서 등 같은 번호가 들어간 구간을 모두 찾아 목록화하고 사람이 확인한다.
2. **검색 표시**: 결과·원문 뷰에 ‘원문 제2026-35호 / 공식 고시 제2026-65호: 번호 불일치, 적용 내용 확인 필요’를 별도 배지로 표시한다.
   원문 인용 자체의 번호를 자동 대체하지 않는다. 충돌 메타데이터가 빠져도 원문은 그대로다.
3. **답변 게이트**: 해당 구간을 근거로 취업 허용·금지 결론을 단정하지 않는다.
   모델 프롬프트만 믿지 않고 결정적인 후처리 경고와 출처 패널에도 양쪽 번호·공식 링크를 노출한다.
   원문 충돌을 ‘공식 고시 본문까지 불일치’로 과장하지 않는다.
4. **회귀 승인 조건**: 동일 앵커 검색, KO/EN 답변, 모델 미응답 fallback, 모바일 원문 뷰, 인용 원문 불변,
   다른 F-4 구간의 오탐 부재를 확인한다. 사람이 공식 고시와 매뉴얼 구간을 대조한 뒤 해소 상태를 변경한다.

이 작업은 아직 구현·배포하지 않은 후속 공개 전 게이트다. 이번 PR의 병합 적합성은
검증 범위를 표시하는 메타데이터·링크 수리로 한정된다. 법률적 내용 전체의 검증 승인은 아니다.
병합 전 소유자의 검토가 필요하며 자동 병합·배포는 하지 않는다.

검사: 법령 회귀, KO/EN 표시 회귀, 기존 생성물 검사와 저장소 전체 CI 결과는 PR 본문에서 확인한다.
