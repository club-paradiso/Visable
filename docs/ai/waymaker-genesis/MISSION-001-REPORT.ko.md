## B. korean-law-mcp 분석

- **조사한 시점:** 커밋 `0a8f08e`, 버전 4.15.9, MIT 라이선스입니다. 코드는 읽기만 했고 실행하지 않았습니다.
- **규모:** 도구 99개를 등록하고 그중 10개를 공개합니다. 공식 API 대상(target)은 약 50개를 호출합니다.
- **잘하는 점:** 법령ID로 법령명이 바뀌어도 같은 법령을 따라갑니다. 시행일별 버전을 고정하고 공포됐지만 아직 시행 전인 개정을 표시합니다. 부칙 전체와 별표 표도 다룹니다.
- **README보다 약한 점:**
  - 조문 내용 대조는 조문 제목의 느슨한 유사도만 봅니다. 일부러 틀린 제목도 실제로 통과했습니다.
  - 호·목은 검증하지 않습니다.
  - 인용은 현재 시점 기준으로만 확인합니다.
  - 경과규정은 최대 6개만 보여 줍니다.
- **가져오면 안 되는 부분:**
  - 법제처 사이트의 봇 차단을 우회하는 코드가 있습니다. 라이선스가 없는 프로젝트를 다시 구현한 것입니다.
  - 일부 파일은 저자의 다른 프로젝트 LexDiff에서 옮겨 왔다고 적혀 있습니다. LexDiff는 2026-04-13부터 BSL 1.1(비운영용)입니다.
  - 두 부분 모두 Waymaker에서 쓰지 않습니다([03](03-reference-provenance.md)).
- **결론:** 버전 추적, 부칙, 별표라는 아이디어는 공식 API 명세를 바탕으로 직접 다시 설계했습니다. 사용자 질문을 외부 호스팅 서버로 보내지 않습니다([02](02-korean-law-mcp-study.md)).

## C. 기존 Waymaker 평가

- **이미 있는 것:**
  - 법령 클라이언트(`law_tools.py`). 테스트하기 좋은 전송 계층과 오류 유형이 갖춰져 있습니다.
  - 검토 단계를 강제하는 지식 플랫폼
  - 승인된 매뉴얼만 쓰는 매뉴얼 레지스트리
  - 규칙 기반 분류기 두 개(Python, JS)
- **빠진 것:**
  - 법령 버전과 시행일 개념이 없습니다. `efYd`, 연혁, 부칙을 쓰지 않습니다.
  - "법령이 있다"와 "주장이 맞다"를 구분하지 못합니다.
  - 조회 실패를 '없음'으로 처리합니다.
- **가장 심각한 사용자 노출 결함(미수정, 운영자 판단 필요):**
  - 체류자격 안내 데이터가 출입국관리법 시행규칙 제73조의 **2027-09-16 시행 문구**를 현행으로 표시합니다.
  - 그 결과 "등록증 수수료를 카드로 낼 수 있다"는 안내가 나갑니다. 하지만 2026-10-19 현재 시행 중인 제1호 가목은 현금이나 현금 납입 증표만 허용합니다.
  - 이 내용은 원문 캡처로 직접 확인했습니다.
- **운영상 위험:**
  - 운영 답변 경로가 NVIDIA API Trial 약관이 적용되는 무료 모델 경로를 씁니다. 이 약관은 운영 용도 사용을 금지합니다. 법률 검토가 필요합니다.
  - `law_query_normalizer.py`의 출처 문제도 법률 검토가 필요합니다.
  - 기본 진단 모드가 열려 있던 문제는 #666과 토큰 설정으로 해결했습니다.

## D. 독자 설계(WLIE)

- **새 서비스를 만들지 않았습니다.** 순수 로직 세 가지를 실험 패키지에 두었습니다.
  - 식별·시간 판정기
  - 7단계 주장 검증기
  - 크기 상한이 있는 근거 패키지
- **기존 것을 다시 씁니다.** 법령 클라이언트, 지식 플랫폼, 매뉴얼 레지스트리는 기존 것을 그대로 쓰고 중복을 만들지 않았습니다.
- **식별 규칙:** 법령명은 식별자가 아닙니다. 법령ID가 정체성이고 버전은 (법령일련번호, 시행일) 쌍입니다. 실제로 시행규칙 289833 하나가 2026-09-15와 2027-09-16 두 시행일로 올라 있습니다.
- **핵심 불변식:**
  1. 조회 실패는 '없음'이 아닙니다.
  2. 일부만 확인된 색인에서 찾지 못한 것도 '없음'이 아닙니다.
  3. 비슷한 이름의 법령으로 바꿔치기하지 않습니다.
  4. 조문이 존재한다고 해서 주장이 맞다는 뜻은 아닙니다.
  5. 가져온 원문은 데이터일 뿐 지시가 아닙니다.
  6. 출처끼리 충돌하면 순위로 고르지 않고 충돌 기록을 남깁니다.
- **베끼지 않았다는 근거:**
  - 스펙은 Waymaker의 요구와 공식 API 명세에서 출발해 직접 썼습니다.
  - 구현 에이전트에게는 참조 저장소를 보지 말라고 지시했습니다.
  - 다만 코드 유사도를 별도로 검사하지는 않았습니다. PR 리뷰 항목으로 남깁니다.

## E. 공식 법령 데이터 전략

- **API 구조:** 법제처 공개 API(open.law.go.kr)는 목록용 `lawSearch.do`와 본문용 `lawService.do` 두 엔드포인트로 이뤄집니다. 가이드 191건 중 55건을 확인했습니다.
- **필요한 버전 계열:**
  - 시행일 기준 법령: `eflaw`, `eflawjosub`
  - 조문별 변경이력: `lsJoHstInf`
  - 일일 변경 피드: `lsHstInf`
- **부칙과 별표:** 부칙은 본문 안에 있습니다. 별표는 본문의 별표 항목과 파일 링크로 받습니다.
- **이용 조건:**
  - 저작권법 제7조에 따라 법령과 판결은 저작권 보호를 받지 않습니다.
  - 출처를 법제처로 밝혀야 하고 효력은 관보가 기준입니다.
  - AI 학습 이용에 대한 법제처의 명시적 입장은 찾지 못했습니다.
- **식별 정보:** 2026-10-19에 법령 15종과 행정규칙 7건(22건)의 식별 정보를 공개 웹에서 직접 확인했습니다. 확인한 시행 예정 개정은 다음과 같습니다.
  - 국적법: 2026-12-03 시행 예정
  - 외국인고용법: 2026-12-10, 2027-06-10 두 차례 시행 예정
  - 재외동포법 시행규칙: 2027-09-16 시행 예정
  - 출입국관리법 시행규칙 제73조: 2027-09-16 시행 예정
- **Waymaker가 저장한 낡은 값:**
  - 출입국관리법과 시행령 버전이 구 버전입니다.
  - 국적법 시행령·시행규칙 식별 정보가 낡았습니다.
  - F-4 고시 번호가 다릅니다(제2026-35호 대 제2026-65호).

## I. 학습·증류 전략

- **원칙:** 계속 바뀌는 법령을 모델 가중치에 외워 넣으면 안 됩니다. 법령 지식은 검색과 검증으로 다룹니다.
- **기법별 비교:**
  - SFT·QLoRA는 분류와 구조화 출력처럼 안정적인 능력에만 씁니다.
  - DPO, ORPO, 지속 사전학습은 지금 하지 않습니다.
- **증류 가능 여부는 가중치 라이선스가 아니라 모델을 제공받는 경로가 정합니다.**
  - 자체 호스팅한 gpt-oss, Gemma 4, Nemotron(OpenMDW), Llama 3.x는 조건부로 허용됩니다.
  - OpenAI API, Anthropic API, NVIDIA Trial, Thinking Machines 무료 경로는 허용되지 않습니다.
- **운영 원칙:** 교사 모델의 사고 과정을 요청하지 않습니다. 교사 모델의 법적 결론은 WLIE 검증과 사람 검토를 거치기 전에는 정답 라벨로 쓰지 않습니다. 교사 정책(`configs/teacher_policy.json`)은 법률 서명 전까지 모든 교사 기록을 막습니다.
