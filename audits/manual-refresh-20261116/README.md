## 6. 남은 일 · 승격 전 관문

- `index.html` 하단 `manualNote`(9개 언어 팩 포함)는 여전히 "사증 2026-10-19, 체류 2026-11-02"를 적습니다. 구조화된 안내가 그 판을 따르는 것은 맞으므로 그대로 두었습니다.
1. 원본 SHA-256을 공식 게시본과 대조하고, 공식 게시 주소와 시행일(특히 #5 경과 규정의 ’26. 12. 31. 기준)을 확인합니다.
2. 공식 PDF(또는 한컴 뷰어 출력)를 받아 쪽 말뭉치를 다시 만듭니다(`npm run build:current-manuals`).
3. 위 항목을 관련 법령·고시와 대조하고(#6 금액 포함), 검토자·검토일을 `data/manual_approval_index.json`에 기록합니다.
4. 승인 후에만 `current` 승격, 쪽 말뭉치·검색 색인·근거 데이터·체류자격 안내 문구 갱신을 같은 변경에서 진행하고, 그때 `data/manual-updates/`의 알림을 비웁니다.

**안전 원칙:** 검토 전 내용은 `검토 전`으로 표시되고, 이미 검토된 운영 요건을 덮어쓰거나 최신 법적 효력 규정처럼 보여서는 안 되며, AI 답변의 직접 근거로 쓰이지 않습니다.
