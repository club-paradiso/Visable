# UX/UI 결정 보고서 (PHASE 8)

생성: 2026-06-11

## 우선순위 원칙
P1/P2(서류 정확성·중복 제거)가 시각 작업보다 우선. 시각 변경은 기능 무파괴·법적 명확성 보존 범위로 한정.

## 결정 사항

1. **검색/히어로**: 레거시 장식(별 캔버스, 스포트라이트, 무한 스크롤 큐, 사진 무한 줌)을 제거해
   검색이 첫 시선이 되도록 정리. 히어로는 정적 종이 배경. 시맨틱 헤딩 구조 유지.
2. **게이트웨이 행동 카드**: 구조 변경 없이 시각 위계만 조정(키치 테마에서 파일-폴더 카드 +
   AI 카드에만 핑크 탭). 검색 vs HiKorea 예약 vs Waymaker(AI)의 구분은 기존 카피 유지 + 테마
   대비로 명확화. 법적 콘텐츠처럼 보이지 않도록 카드형 유지.
3. **결과 카드(.vc)**: 둥근 모서리·보더 대비 유지, 키치에서 폴더 시트 + 헤더 인덱스 엣지.
   접힘/펼침 동작 무변경.
4. **서류 섹션 (핵심 변경)**:
   - 사용자 그룹을 `기본 준비서류 / 상황별 추가서류 / 심사 중 추가 요청 가능` 3종으로 재구성
     (내부 4버킷 데이터 모델 보존, 표시 전용).
   - 재량 문구는 체크리스트 타일이 아닌 ※ 주의 노트 블록으로 분리.
   - 빈 그룹 자동 숨김(renderDocGroup 기존 동작 활용).
   - 모든 그룹 하단에 Paradiso 분류 고지 노트 1줄.
   - 타일에 `word-break: keep-all; overflow-wrap: anywhere; line-height 1.5` — 한국어 줄바꿈 개선.
   - 중복 카드 제거: 렌더 가드(아이디 해석 + 패밀리 키 + 구체 라벨 우선 병합).
5. **출처·경고 패널**: 의미·문구·크기 무변경. 키치에서도 장식 배제(팔레트만). 대비 유지.
6. **AI 핸드오프**: `.ai-fab` min-height 44px (전 테마). 키치에서 종이 필 + 잉크 보더 + 파란 스파크,
   표시명 "Waymaker by Paradiso"(표시 전용 스왑, 내부 식별자 불변).
7. **모바일**: 신규 요소는 기존 그리드/랩 규칙 내에서 동작(가로 오버플로 신규 요인 없음 —
   추가한 블록은 모두 block/grid flow). 375px 스모크는 QA 체크리스트 항목화.
8. **접근성**: focus-visible 보존, prefers-reduced-motion에서 키치 hover 변환 제거 +
   ai.html ambient/status-dot 애니메이션 정지 규칙 추가. 경고는 색상 단독 의존 없음
   (※ 마커, NO SOURCE 배지, role=alert/note).

## !important 정책
신규 블록은 캐스케이드 말미 배치로 !important를 회피. 부득이 3곳만 사용(레거시 !important
배경 규칙 중화: 키치 랜딩 배경 1, 히어로 사진 워시 숨김 1, 다크모드 배경 중화 1) — 각 위치에
인라인 사유 주석. 기존 !important 제거는 회귀 위험 대비 이득이 작아 보류(보고로 갈음).
