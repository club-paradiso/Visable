# 외부 참조 사이트 대조 보고 — visainkorea.com (2026-07-02)

## 경위

- 사용자가 지목한 `visainfo-korea.com`은 정확 일치 웹검색 0건 + 직접 접속 차단으로 실체를
  확인할 수 없었고, 사용자 확인을 거쳐 유사 도메인 **visainkorea.com(장행닷컴행정사)** 으로 진행.
- 이 작업 환경은 보안 프록시가 모든 외부 HTTP 접근을 차단(curl·WebFetch 전부 403)하므로
  직접 크롤링/파싱은 불가. **WebSearch 도메인 필터 스니펫 스윕(9회)** 으로 주제 색인만 수집.
  → 전문(full-text) 수집이 필요하면 사이트 저장본 업로드 방식(매뉴얼 HWP 방식과 동일)을 권장.

## 원칙 (중요)

- 민간 행정사 사이트는 이 프로젝트의 출처 정책상(`sourcePolicy.unofficialSourcesAllowed: false`)
  **법적 근거로 사용 불가**. 수집물은 "사용자들이 실제로 묻는 주제" 발굴 전용.
- 제품에 반영한 것은 ① 검색 별칭(법적 내용 아님) ② 렌더러 검색 개선뿐이며,
  모든 사실 문구는 공식 매뉴얼 원문 대조를 통과한 것만 반영 대상.
- 사이트 원문 프로즈는 저작권상 복제하지 않음(주제·URL 색인만 저장).

## 이번에 반영한 것 (전부 비법적·검색성 개선)

1. **렌더러 수정** (`index.html`, PARADISO_SEARCH_ALIAS_FIX_20260702):
   `searchAliases`(레코드·세부코드의 큐레이션 한글 별칭)가 지금까지 **정확 코드형 질의에서만**
   작동하고 일반 단어 검색에서는 무시되던 문제를 수정 — calculateScore의 별칭 목록과
   getRecordSearchText에 searchAliases 포함. 기존에 쌓여 있던 별칭 자산 전체가 단어 검색에서
   살아남 (예: "산재"→G-1, "임금체불"→G-1 최상위 확인).
2. **수요 기반 별칭 추가** (저작 레이어 → 재생성):
   - D-2: 아르바이트 · 알바 · 시간제취업 · 유학생 아르바이트
   - D-4: 아르바이트 · 알바 · 시간제취업
