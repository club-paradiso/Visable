# Source extraction notes (short-stay country checker)

## 추출 방법

1. **B-1 / B-2-1 국가표**: `docs/data/claude_opus_manual_extraction_2026_05/visa_hwp_full.txt`
   (2026.5 사증발급 안내매뉴얼 HWP 전체 추출본)의
   `사증면제협정 체결국가 일람표(2022.9.22 기준)` 및 `무사증입국 허가대상 국가 일람표`
   섹션을 직접 열람·대조하고, 레포에 이미 검수·저장된 B-1-1/B-1-2/B-2-1 서브코드
   목록(visa_data.json, B-1 저장 기준일 2024-12-04 / B-2-1 2022-11-01)과 병합해
   `fixtures/b1_visa_waiver.json`, `fixtures/b21_general_visa_free.json`으로 고정.
2. **제주 B-2-2 고시 목록**: 매뉴얼 추출본에는 고시 국가 목록 전문이 없음
   (간접 언급만 존재). 과업 명세가 제공한 법무부고시 제2022-189호/재외공관 게시 사본
   (2023-09-18) 목록(불허 22 + 확대허가 34/1/29)을 `fixtures/jeju_b22_notice.json`으로
   고정하고, 레포 기존 B-2-2 데이터(제외국 23개국)와 대조.
3. **K-ETA**: 공식 누리집 실시간 조회 불가(환경 네트워크 정책상 HTTP 403).
   마지막 확인 저장 사본(수수료 1만원, 비자 아님, 유효기간, 연령 면제, 한시 면제
   22개국·지역)을 `fixtures/keta_program.json`으로 고정.
4. **C-3 분류**: 매뉴얼 C-3 장 + 레포 C-3 서브코드(11종)에서 목적별 매핑만 추출
   (`fixtures/c3_fallback.json`). 서류 요건은 새로 발명하지 않고 기존 데이터/매뉴얼
   문구 범위로 한정.
5. **F-4**: visa_hwp_full.txt의 `재외동포(F-4) 사증·체류관리` 장(대상·서류·거소신고
   90일·취업제한·병역 제한)과 `별첨1 해외 범죄경력증명서 제출기준`(FBI·아포스티유·
   6개월 유효·번역공증)을 직접 열람해 `data/f4/routes.json`의 근거로 사용.
6. 모든 표는 fixtures에서 스크립트로 재생성(`scripts/update_short_stay_rules.mjs`,
   본 표 문서 생성 포함)하여 손 전사 오류를 차단.
