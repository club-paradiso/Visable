# Short-stay checker — 제주→본토 경로 오해 제거 + 팝업 UI 전환 (2026-06)

## 요청 (사용자)
1. 국적별 단기입국 경로 확인을 **메인 화면을 길게 늘이는 대신 페이지 내 팝업(모달) UI**로 처리.
2. 방문 지역이 **"제주 입국 후 본토 이동 희망"(`jeju_then_mainland`)**일 때 **절대로
   "제주 무사증 + 체류지역 확대허가 확인"** 같은 답변이 나오면 안 됨 — 체류지역 확대허가는
   **원칙상 허용되지 않으므로** 사용자가 오해하지 않도록 정확한 워딩으로 수정.
3. 법령·매뉴얼상 **필요한 비자가 명백히 확정된 경우**, 굳이 "다른 가능성"을 표시하지 않아도 됨.

## 근거 (저장 출처 기준 — 실시간 법령 조회 불가)
- `visa_data.json` B-2-2: **"⚠ 제주 한정 체계로 안내되므로, 타 지역 이동 가능 여부는 별도
  확인 필요. 체류기간 30일."** → 제주 무사증은 체류지역이 제주로 한정되는 제도.
- `data/short-stay/fixtures/jeju_b22_notice.json`(법무부고시 제2022-189호 사본): 제주 무사증
  입국 후 본토 이동이 **자동으로 허용되지 않음**.
- 제주 무사증은 체류지역을 제주특별자치도로 한정하는 제도이며, 본토로의 **체류지역 확대는
  원칙적으로 허용되지 않는** 예외적 조치임. 따라서 "확대허가 확인"을 정상 경로처럼 제시하면
  사용자에게 오해를 준다.

> CLAUDE.md 준수: 새로운 법적 요건을 발명하지 않음. 기존 저장 데이터/출처의 사실
> (제주 한정·본토 이동 비자동허용)을 **렌더러(checker) 차원에서 오해 없이 표현**하도록만 수정.

## 변경 내용

### 1) 엔진 로직 — `assets/js/short-stay-checker.js`
`jeju_then_mainland`을 **본토를 실제로 갈 수 있는 경로**로 결정하도록 전용 분기로 교체:
- 일반 무사증 대상국(B-1 사증면제협정 / B-2-1·K-ETA) → **일반 무사증 경로**(체류지역 제한
  없음)로 `likely_available`. 허용기간 초과 시 사증(C-3) 필요로 전환.
- 일반 무사증 비대상국 → **목적별 C-3 사증 필요**(`visa_required`).
- 두 경우 모두 다음 문구를 명시:
  > "제주 무사증(B-2-2)은 체류지역이 제주특별자치도로 한정되는 별도 제도이며, 제주에서
  > 본토(타 지역)로 이동하는 체류지역 확대는 **원칙적으로 허용되지 않습니다**."
- `"제주 무사증 + 체류지역 확대허가 확인"` / `"제주 무사증 + 본토 이동 가능 여부 공식 확인"`
  경로 라벨과 `phraseExpansionPermit()` 헬퍼 **완전 제거**.
- (요청 3) 본토 목적이 확정된 분기에서는 **혼동을 주는 "제주 무사증(B-2-2)" 다른 가능성**을
  제거. `jeju_then_mainland`은 경로 확정 시 "다른 가능성"을 표시하지 않음. 명시적 "한국 본토"
  결과에서도 제주 무사증 교차안내를 제거(같은 목적 내 보조경로 C-3-2/C-3 폴백은 유지).
- `jeju_only`(제주만 방문) 동작은 그대로 유지.

### 2) UI — 페이지 내 팝업(모달)
- 인라인 `<section id="shortStayChecker" … hidden>` → **`#shortStayModalOverlay` 모달**
  내부의 `#shortStayChecker`로 이동(`index.html`). 기존 사이트 모달 인프라(`openModal`/
  `closeModal`, 포커스 트랩, ESC, 오버레이 클릭) 재사용.
- 관련 검색 후에도 **페이지를 자동으로 늘이지 않음**: 폼만 미리 렌더하고, 진입은 CTA/유틸리티
  버튼(`data-action="open-short-stay"`)으로 팝업을 연다.
- 모달 안에서는 모듈이 중복 제목을 렌더하지 않음(모달 헤더가 제목 담당).

### 3) 검증 — `scripts/check_short_stay_rules.mjs`
- VN `jeju_then_mainland` 기대치를 **C-3-9 visa_required + "원칙적으로 허용되지 않" + 다른
  가능성 0개**로 교체. JP `jeju_then_mainland`(B-2-1 likely_available) 시나리오 추가.
- 소스 가드 추가: `"제주 무사증 +"` 라벨이 더 이상 생성되지 않음 / "체류지역 확대는 원칙적으로
  허용되지 않습니다" 문구 존재 / `#shortStayModalOverlay` 호스트 존재.
- 전체 `node scripts/check_short_stay_rules.mjs` → **74 checks, 0 failures**.
