- 적용 장치: `scripts/visa/manual_ref_promotion_2026_10.py` (빌드 때 적용, `scripts/visa/build_visa_data.py`가 부른다)

이 문서는 법적 정확성을 다시 확인한 결과가 아닙니다.
`manualRefs`가 가리키는 문구가 2026.10 판 어느 쪽에 있는지 기계적으로 대조한 기록입니다.

## 1. 배경

- 소유자가 2026-10-23에 2026.10 판(파일 날짜 2026-10-19)을 기준 판본으로 정했습니다.
- 앞 단계(2026-10-19)에서 2026.6 → 2026.9로 옮긴 인용은 이번에 2026.9 → 2026.10으로 옮깁니다. 방법은 2026.9 때와 같습니다(`audits/manual-ref-edition-2026-09/README.md` §2).
  1. 영역을 나눕니다. 체류 인용은 체류 매뉴얼에서만, 사증 인용은 사증 매뉴얼에서만 찾습니다.
  2. `section` 문구가 인용한 옛 쪽(2026.9 PDF 또는 2026.6 추출본)에 그대로 있어야 합니다.
  3. 옛 쪽을 본문 내용으로 2026.10 쪽에 대응시킵니다.
  4. 같은 문구가 대응된 2026.10 쪽에 그대로 있어야 합니다.
- `visa_data.json`은 직접 고치는 파일이 아니라 `backend/data/visa_authoring/`에서 빌드되는 생성 파일입니다. 그래서 2026.9 단계와 같이 이 보고서를 고정해 두고, 빌드 때 확인된 인용만 바꿉니다. 인용마다 기록된 판본·파일·쪽·구간이 정확히 같을 때만 바꾸고, 다르면 빌드가 실패합니다.
