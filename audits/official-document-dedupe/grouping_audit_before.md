# 문서 그룹핑 감사 (before)

원문 매뉴얼은 단일 보편 분류(공통/필수/조건부)를 사용하지 않습니다(제출서류·신청서류·첨부서류·기본서류·추가서류·심사에 필요한 추가서류 등 국지 표제 혼용).
아래 매핑은 **표시 전용 UX 분류**이며 공식 표제가 아닙니다. 데이터의 내부 키는 변경하지 않습니다.

| 원본(내부) 버킷 | 성격 | 사용자 표시 그룹 | 비고 |
| --- | --- | --- | --- |
| addReqDocs | 레거시 doc-id 배열 | 기본 준비서류(맥락별) |  |
| additionalDocs | Paradiso 내부 분류 키 (원문 매뉴얼 보편 표제 아님) | 상황별 추가서류 |  |
| changeReqDocs | 레거시 doc-id 배열 | 기본 준비서류(맥락별) |  |
| commonDocs | Paradiso 내부 분류 키 (원문 매뉴얼 보편 표제 아님) | 기본 준비서류 |  |
| conditionalDocs | Paradiso 내부 분류 키 (원문 매뉴얼 보편 표제 아님) | 상황별 추가서류 | '조건부 서류'는 보편 공식 표제가 아니므로 사용자 표기는 '상황별 추가서류'로 대체 |
| documents_extension | 레거시 표시 배열(name/note) | 기본 준비서류(맥락별) |  |
| documents_initial | 레거시 표시 배열(name/note) | 기본 준비서류(맥락별) |  |
| documents_registration | 레거시 표시 배열(name/note) | 기본 준비서류(맥락별) |  |
| extReqDocs | 레거시 doc-id 배열 | 기본 준비서류(맥락별) |  |
| extensionReqDocs | 레거시 doc-id 배열 | 기본 준비서류(맥락별) |  |
| initialReqDocs | 레거시 doc-id 배열 | 기본 준비서류(맥락별) |  |
| newReqDocs | 레거시 doc-id 배열 | 기본 준비서류(맥락별) |  |
| requiredDocs | Paradiso 내부 분류 키 (원문 매뉴얼 보편 표제 아님) | 기본 준비서류 |  |

표시 그룹(순서 고정): 기본 준비서류 → 상황별 추가서류 → 심사 중 추가 요청 가능(주의 노트로 표시)
