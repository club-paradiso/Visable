### 실행 전에 막힌 두 번

- **첫 번째:** Colab 기본 torch가 2.11.0에서 2.14.1로 바뀌어 있었습니다. CUDA 사전 검사가 재현 고정값과 다르다며 모델 적재를 막았습니다. 모델은 한 번도 답을 내지 않았습니다.
  노트북에 감사한 실행과 같은 `torch==2.11.0+cu130`(torchvision·torchaudio 짝 버전 포함) 설치 한 줄을 넣었습니다. 코드 커밋, 계약, 게이트, 문턱값은 그대로입니다.
- **두 번째:** 런타임 삭제가 실제로는 되지 않아 같은 커널이 남았습니다. 이미 불러온 torch 2.14.1 위에 2.11.0이 깔려 모델 적재가 `ImportError`로 실패했습니다. 이때도 모델은 답을 내지 않았습니다.
  `google.colab.runtime.unassign()`으로 VM을 반납하고 새 VM에서 다시 시작했습니다. 이번 결과 폴더는 새 VM에서 처음 만들어졌습니다(`previous_sessions: 0`, 세션 2건).
- 실패한 두 시도의 파일은 사라진 VM에만 있었고 이 결과에는 들어가지 않았습니다.

## 2. 고르는 질문 여섯 건

질문이 두 체류자격 코드 중 어느 쪽인지 묻고 근거가 둘 다 말하면, 처음 부를 때 `choice_codes`로 두 코드를 알려 줬습니다. 여섯 건 모두 표시가 붙었습니다.

| 문항 | 질문 언어 | 처음 답 | 다시 묻기 | 사용자에게 나간 답 |
|---|---|---|---|---|
| 02 | 베트남어 | 두 코드 모두 | 없음 | 모델 답 |
| 81 | 베트남어 | 두 코드 모두 | 없음 | 모델 답 |
| 68 | 영어(베트남어로 답 요청) | 맞는 코드만 | 다른 코드 추가 | 모델 답 |
| 45 | 한국어 | 맞는 코드만 | 그대로 | 모델 답 + 근거 인용 안내 |
| 70 | 한국어 | 맞는 코드만 | 그대로 | 모델 답 + 근거 인용 안내 |
| 62 | 영어 | 맞는 코드만 | 그대로 | 모델 답 + 근거 인용 안내 |

- 맞는 코드를 고르는 데는 여섯 건 모두 성공했습니다. 빠진 것은 다른 코드에 대한 설명입니다.
- 두 코드를 모두 말한 답은 세 건 모두 베트남어로 쓴 답입니다(02·81·68). 005-V에서도 다시 묻기가 통한 두 건은 베트남어였습니다. 한국어와 영어 답에서는 표시도 다시 묻기도 효과가 없었습니다.
- 원 모델 채점은 처음 답을 봅니다. 그래서 45·62·68·70은 원 모델에서 떨어졌습니다. 이 네 건은 범주가 모두 달라서 각 범주가 2/3로 문턱(0.66)에 걸쳤습니다.
  005-V에서는 한 범주에 고르는 문항이 둘씩 있어 1/3로 떨어졌습니다. 범주마다 한 건씩 둔 것은 005-W 동결 때 정한 설계이고, 결과를 본 뒤 바꾼 것이 아닙니다.
  **다만 이번 통과를 "표시가 처음 답을 고쳤다"는 뜻으로 읽으면 안 됩니다.** 한국어·영어 처음 답에서는 효과를 확인하지 못했습니다.
