## 3. 남은 실패

- **두 언어를 요청한 질문(A05K-69, 모델).** "Trả lời bằng tiếng Anh hoặc bằng tiếng Hàn đều được"처럼 서로 다른 언어 요청이 둘이면, 명세대로 질문 언어(베트남어)를 답 언어로 정합니다.
  모델은 질문에 남아 있는 요청 문장을 보고 영어로 답했고, 응답 검사가 검토로 돌렸습니다. 005-H의 A05H-69와 같은 실패입니다.
- **부분 답의 빠진 항목(A05K-41·47).** 시스템 안내가 채워 끝단은 맞았습니다. A05K-41은 빠진 항목 대신 프롬프트 문장("Each item in uncovered_items is not in the evidence")을 그대로 옮겨 적었습니다.

## 4. 다음 미션(005-L) 제안

남은 것은 한 가지 행동입니다. 기준은 그대로 둡니다.

1. **언어 요청 문장도 모델에게서 뺌.** 답 언어는 이미 시스템이 정해 `reply_language`로 넘기므로, 질문의 언어 요청 문장("in English", "bằng tiếng Anh", "한국어로" 등)을 답변 지시 문장처럼 모델에게 주는 질문에서 뺍니다.
   결정적이고, 005-J의 질문 정리와 같은 방식입니다.
2. 부분 답에서 프롬프트 문장을 옮겨 적는 것은 계약 문구에서 그 문장을 "답에 쓰지 말라"고 다시 적는 방안을 개발 집합에서 먼저 봅니다. 끝단은 시스템 안내가 이미 맞춥니다.
