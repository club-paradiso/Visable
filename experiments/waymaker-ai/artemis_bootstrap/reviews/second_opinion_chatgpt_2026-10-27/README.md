## 파일 안내

- `handoff-index.json`: 140문항의 ID, 질문, 관찰된 판정, 고칠 내용과 메모를 한곳에 모은 목록. `changes`에는 6개 수정 전후 데이터와 실제 저장된 모델 답변의 재채점 결과가 있다. `legal_review_completion: unconfirmed`는 검증 완료가 확인되지 않았다는 뜻이다.
- `originals/`: 검토표 내보내기에 기록된 SHA-256과 일치하는 원본 문항 파일 6개. 원본은 동결 자료이므로 직접 덮어쓰지 않는다.
- `partial-v2/`: 6문항을 수정한 부분 버전 3개. 나머지 문항은 원본과 동일하며, 전수 법률 검증을 거친 최종 라벨 세트가 아니다.
- `check_integrity.py`: ID와 순서, 원본 SHA-256, 수정 문항의 대응 관계를 확인한다. 실행: `python3 check_integrity.py`. 법률 정확성이나 실제 검토표의 저장 상태는 검증하지 않는다.
