# SOURCE POLICY — 출처·재사용·저작권 원칙

이 코퍼스의 모든 자료는 아래 원칙을 따릅니다. 원칙을 확인할 수 없는 자료는 수집하지 않으며, 수집한 것처럼 표시하지 않습니다. (기준일: 2026-11-04)

## 1. 공식 출처만 사용한다

- **1순위 출처**: 국가법령정보센터 (법제처) — `law.go.kr`, 공동활용 Open API `open.law.go.kr`.
- **영문 번역 제공자**: 한국법제연구원(KLRI) — 국가법령정보센터 영문법령 페이지가 그대로 중계합니다. 페이지 상단 고지문("이 영문법령은 한국법제연구원에서 제공하는 것으로…")으로 확인했습니다.
- **행정규칙**: 법무부 고시도 국가법령정보센터 행정규칙 본문으로 수집합니다.
- 블로그, 일반 위키, AI 생성 요약은 법령 원문으로 사용하지 않습니다. 법령명이 일부만 일치하는 다른 법령을 가져오지 않습니다 — 법령ID(DRF `ID`)와 법령일련번호(`MST`)로 정확히 식별합니다.

## 2. 한국어 법령 본문: 전문 저장 가능 (근거)

- 「저작권법」 제7조: 법령은 "보호받지 못하는 저작물"입니다.
- 법제처 '법적효력/저작권' 안내 및 open.law.go.kr 저작권 정책 (2026-11-04 확인): "공공데이터 정책에 따라 국가법령정보센터에서 제공하는 법령정보는 누구에게나 개방되어 있으며, 제공된 법령정보는 영리 목적의 이용을 포함하여 자유로운 활용이 보장됩니다."
- 조건: **출처 표시** (각 파일의 메타데이터와 Markdown 헤더에 출처·URL·식별자 명시), **위조·변조 금지**, 법제처 이외의 기관을 출처로 명기하는 행위 금지.
- 따라서 이 코퍼스는 한국어 원문을 의역·축약 없이 전문 저장하되, 제공자 HTML의 하이퍼링크 때문에 생기는 공백 차이를 정규화합니다 (조사·어미가 링크 경계에서 떨어져 표기되는 것을 원문 표기로 재결합). 단어의 추가·삭제·순서 변경은 하지 않으며, 이 정규화 규칙은 `backend/services/legal_corpus/parser.py`에 코드로 고정되어 있습니다.

## 3. 영문 번역본: 본문 저장·재배포 금지 (근거)

- KLRI 저작권지침 (elaw.klri.re.kr, 2026-11-04 확인): "한국법제연구원에서 제공되는 자료에 대한 무단 복제 및 배포는 원칙적으로 금합니다."
- KLRI FAQ: 영문법령을 홈페이지 등에 게재하려면 **저작권 사용계약**이 필요하고, 승인 기관은 **Open API 실시간 연동** 방식으로만 서비스할 수 있습니다.
- 대한민국영문법령 공동활용시스템 약관 제20조: 영문법령정보를 활용한 데이터베이스 구축, 제3자에 대한 재제공을 금지합니다.
- 시행규칙 영문본처럼 소관부처(법무부) 번역으로 표시되는 경우도 동일한 취급을 합니다 — 재배포 허락을 확인하지 못했기 때문입니다.

**따라서 이 코퍼스는 영문에 대해 다음만 저장합니다**: 번역 존재 여부, 대응 한국어 버전(공포번호·시행일·MST), 조문 번호와 영문 조문 제목, 조문별 본문 해시(SHA-256), 공식 출처 링크. `en.md` / `articles.en.json` 같은 본문 파일은 만들지 않으며, 검증기가 이 파일들의 존재 자체를 오류로 처리합니다.

AI 번역본은 공식 번역과 엄격히 분리합니다. 이 코퍼스의 공식 병렬 자료에는 AI 번역을 포함하지 않습니다.

## 4. 별표 파일 (HWP/PDF)

- 별표 7 PDF는 국가법령정보센터가 제공하는 공식 파일을 바이트 그대로 보존하고 해시를 기록합니다.
- 주의: 법령 페이지의 다운로드 링크 라벨(형식 표시)과 실제 파일 형식이 일치하지 않는 경우가 실측됐습니다 (별표 7: flSeq 170813011 = HWP, 170813013 = PDF인데 페이지 라벨은 혼재). 그래서 파일 형식은 매직 바이트로 판정합니다.

## 5. 인증정보·개인정보

- DRF Open API의 OC는 호출자 식별자이므로 저장소, 로그, PR 본문 어디에도 기록하지 않습니다. 환경변수 `LAW_API_OC`로만 주입합니다.
- 법령 자료 자체에는 개인정보가 포함되지 않습니다. 수집 대상은 공표된 법령·고시뿐입니다.

## 6. 확인하지 못한 것은 확인하지 못했다고 기록한다

- 영문본이 없으면 `translationAlignment: NOT_AVAILABLE`로 기록하고 이유를 남깁니다 (COVERAGE_REPORT.md, ENGLISH_ALIGNMENT.md).
- API 접근이 실패하면 기존 저장본을 삭제하거나 최신으로 간주하지 않습니다. 실패는 종류(timeout/http/network/parse)로 분류해 보고합니다.
- 메타데이터에서 모르는 값은 추측으로 채우지 않고 `null`로 둡니다.
